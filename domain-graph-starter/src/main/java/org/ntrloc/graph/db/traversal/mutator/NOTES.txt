The role of the mutator is to simplify the creation, update and deletion of entries in the ntrloc system.  Under the hood, of course it's all Gremlin, but ntrloc only uses a
fraction of what Gremlin is capable of.  On the other hand, there are patterns that are repeatedly expressed in the Gremlin steps we use, so having a higher-level
API should remove a lot of boilerplate code.
