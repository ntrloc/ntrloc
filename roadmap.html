Roadmap

What's designed, not yet built

ntrloc is under active development. Some of what's below is fully designed and next in line; some is a conceptual direction that hasn't been scoped in detail yet. Nothing here should be treated as a current capability.

Compliance & data governance

Regulatory frameworks

Designed, not yet built. This is the largest planned body of work outside the current core.

Data classification tags

Property- and type-level classification (GDPR personal/sensitive, HIPAA PHI, CCPA, COPPA, and general proprietary/public tags) as the foundation for framework enforcement.

Named framework presets

Per-domain activation of regulatory presets — cross-domain exposure limits, retention limits, and deletion semantics enforced automatically once activated.

Consent as a record

Structured, versioned, auditable consent and legal-basis records linked to the items and properties they cover, with automatic re-evaluation on expiry or revocation.

Provable deletion

Purge, anonymization, redaction, and suppression as distinct deletion modes, each producing a signed deletion certificate.

Extensibility

Scripted, dynamic controllers

Conceptual design only — not yet built.

Domain admins would define custom server-side endpoint logic as scripts via the standard Java Scripting API, with no compile-and-deploy cycle to add or change one. Groovy and GraalVM JavaScript are the planned bundled defaults, chosen for native Java interop and because the JS engine landscape has moved to GraalVM since Nashorn's removal from the JDK. Scripts would go through the same validated, permission-checked pathway any other client uses — never a backdoor into raw internals — and would run on a dedicated, bounded executor so a runaway script can't stall the platform's request handling.

Admin UI

Filling in the current gaps

Editable property values

The schema editor currently displays properties read-only; live-editable inputs are planned.

Users & groups screen

Currently a stub. Real user and group management is a planned development slice.

Delete-row and live dropdowns

Delete-row affordances and live cardinality/usage dropdowns in the schema editor's tables, replacing today's static text.

Graph, query & process

Aggregate queries and workflow

Pagination for aggregates

Faceted/aggregate query results are not yet paginated.

BPMN workflow — in progress

An embedded BPMN process engine (Flowable) with custom persistence integrated into ntrloc's own ledger and permission model, event-triggered process start, and a working visual editor for viewing, editing, and deploying new process versions live.

DMN & CMMN — not started

Declarative decision tables (DMN) and ad hoc, non-linear case management (CMMN) are planned to sit alongside BPMN, but integration specifics haven't been designed yet.

Server-rendered module hosting

A path-prefix convention for multiple hosted, server-rendered apps to coexist within one domain without template/controller collisions — named as a direction, not designed in detail.
