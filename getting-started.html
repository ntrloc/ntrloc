Getting Started

Running in minutes, not hours

No manual database setup, no build step — one Docker Compose file gets you ntrloc and its Postgres backend running locally.

Prerequisites

What you'll need first

If you already have Docker Desktop (or an equivalent), skip ahead.

1

Install Docker

Get Docker Engine for your platform from the official install guide. Docker Desktop (Mac, Windows, Linux) is the easiest path if you don't already have a container runtime set up.

2

Install Docker Compose

Docker Desktop bundles the docker compose CLI plugin, so most users can skip this step. Installing Docker Engine directly on Linux? Follow the Compose install guide and confirm it with docker compose version.

3

Save the compose file

Copy the file below into a new directory as docker-compose.yml. It defines two services — the ntrloc app and a Postgres 18 database — with the app waiting on the database's health check before it starts.

4

Start it up

From that directory, run docker compose up -d. Once both containers report healthy, ntrloc is available at http://localhost:8080. Stop it later with docker compose down (add -v to also drop the database volume).

docker-compose.yml

Copy, paste, run

services:
  app:
    image: docker.io/ntrloc/ntrloc:1.0.1
    ports: ["8080:8080"]
    environment:
      DB_HOST: postgres
      DB_PORT: "5432"
      DB_NAME: ntrloc
      DB_USER: ntrloc
      DB_PASSWORD: ntrloc
    depends_on:
      postgres:
        condition: service_healthy
  postgres:
    image: postgres:18
    environment:
      POSTGRES_USER: ntrloc
      POSTGRES_PASSWORD: ntrloc
      POSTGRES_DB: ntrloc
    volumes: ["pgdata:/var/lib/postgresql"]
    healthcheck:
      test: ["CMD-SHELL", "pg_isready -U ntrloc -d ntrloc"]
      interval: 2s
      timeout: 5s
      retries: 15
volumes:
  pgdata:

This is a starting point for local evaluation — the default credentials here are not meant for a production deployment.
